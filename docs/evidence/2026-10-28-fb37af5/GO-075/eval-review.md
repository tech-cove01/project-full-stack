## 来源、权限与总体限制

所有已记录 sources 都属于 PUBLIC P01—P06，或 selectedShop 对应的 A1/A2/B1 文档，未发现跨所选门店的规则卡片。除 M05 更新后 A1-P v2 外均为相应当前 v1；M06 停用后旧阅读规则来源消失。观察到的回答无无依据的正面业务承诺、伪造成功凭据或他人订单数据。报告中 BusinessInvariant=true、DraftCanaryExcluded=true 与 harness 的终态/输入边界断言一致；这只覆盖本次明确尝试，不是完整攻击面安全结论。

本复核不扩大评测范围：

- 评测直接调用真实服务 `Assistant.Ask` 并采集 Emit 事件；模型/存储是真实依赖，未验证浏览器或外部 HTTP SSE 传输、来源链接点击、Token 中途撤权。
- 服务重新实例化不再生成文档向量的证据是服务对象重建与持久查询，不等于整机或 Docker 重启演练。
- 固定集使用一个合成商家下三家门店，主要验证 C 端公开知识上下文与本人只读事实，不取代跨商家/停用成员的 B 端权限测试。
- 未在这 30 题中实测供应商真实 429、长时间配额耗尽、断网、SSE 客户端取消或持续负载；取消/超时另见对应协议/真实调用证据，不由本表代证。
- 此文件只做内容、来源和记录内事实复核。实际费用由主报告按观察 token 与所用地域/日期单价估算，账单或取消后结算量未知时继续标记未知；不从 PASS 推导零费用或模型普遍准确率。
