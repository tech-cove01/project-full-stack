# GO-031d 模拟支付、取消与超时页面

日期：2026-10-26。开始基线 `0072c867ab1f34d7219e815d04779c651c55d9d0`。本报告记录实现者验证；最终提交 SHA、实际环境与真实运行日志由整票报告关联。当前页面构建/格式检查与真实浏览器执行结果分别记录，未运行的场景不写为通过。

## 页面范围

- 本人未支付订单可确认模拟支付或主动取消，页面明确演示支付不涉及真实资金。动作期间阻止重复点击；先取消旧查询与轮询并推进请求代次，写完成后重新读取本人订单，不用迟到的未支付响应覆盖新状态。
- 网络失败或超时后不自动重发写请求，也不自动切换另一动作。页面先通过本人查询确认当前状态；仍未确认时提示手动重新查询。取消成功仅提示“订单已取消，稍后查看活动”，不承诺可立即再次抢券。
- `PROCESSING` 与未支付订单均使用有界轮询；到达轮询上限后可手动重新查询。支付截止按北京时间展示，能否支付由服务端依据数据库期限判定，浏览器不据本地时间决定业务状态。
- 只有成功读取的本人 `CREATED/orderStatus=2` 详情可展示核销凭证并复制。查询或动作错误、终态和路由变化清除旧凭证。离页同时 abort 读写请求并拒绝迟到响应；已发送写请求是否生效仍以服务端当前订单为准，前端 abort 不代表服务端回滚。
- 展示 `cancelTime/cancelReason`，保留字符串 ID/金额、上海业务时间、404/403 清旧详情及卡片内操作按钮换行。订单列表和商铺页继续复用 GO-030 行为。

## 脚本与真实验证

新增 `scripts/go-order-lifecycle-ui-smoke.mjs`，使用真实 Vue 登录、真实商家发布、抢券 API、Stream 和数据库成单；只对本次订单调整支付截止以控制过期窗口。脚本默认 API `http://127.0.0.1:8082`、WEB `http://127.0.0.1:5174`，要求显式 MySQL/Redis 环境变量，支持既有 Playwright/Chrome 路径及 `BROWSER_TIMEZONE/UI_EVIDENCE`。其余六个控制订单需使用正常支付期限，避免短期限测试配置使它们在执行前自然关闭。

脚本覆盖真实 Vue 模拟支付、刷新与凭证复制/隔离、20 次并发支付只生效一次、取消与幂等重试/不同动作冲突、其他账号 404、到期拒绝支付、无 Redis 提示依赖的数据库扫描关闭、支付响应丢失后只读核实、旧未支付查询不能覆盖新支付结果。进程停机越过支付期限、变更新配置后重启仍关闭旧单的场景由 root 独立验证，不伪装成浏览器脚本已覆盖。

另增加真实延迟提交窗口：独立 mysql CLI 事务持有第七单的库存行锁，代理转发独立真实支付请求后立即中断浏览器响应；首次本人查询仍读取数据库未支付状态。释放真实行锁、等待支付提交后，自动查询读到已支付时须清除此前动作错误及“未确认”提示，并展示本人凭证，且不增加第二次支付 POST。该测试不伪造查询或支付成功响应，mysql 子进程、在途独立请求均在 finally 中释放和等待；先用旧页面复现 FAIL，再修正页面按同一断言回放。

## 敏感凭证、夹具与边界

- Token、核销凭证、短信码、手机号及请求头不写日志或报告；浏览器截图统一遮罩 `[data-sensitive]`、`.redeem-token` 和凭证值容器。失败报告只写安全阶段和固定错误描述，不保留任意浏览器/驱动异常文本。
- 七笔订单都由真实 worker 创建。SQL 只修改指定过期订单的支付期限，是显式时钟夹具；另有真实库存行锁用于延迟支付提交，不使用 SQL 伪造支付/取消状态或凭证。脚本不读取不存在的 Redis 到期键，也不靠删除猜测的 ZSet 制造恢复证据；本实现的超时关闭直接扫描数据库。
- 取消的数据库库存、审计和持久补偿提交可验证；Redis 库存与资格补偿仍留 GO-033。脚本不宣称取消后已释放 Redis 资格或可立刻重新购买。
- 正常成功轮先确认 owned Stream 消息已被 worker ACK，再按 voucher→inventory 锁顺序清理 owned 持久生产者，从 XRANGE 筛选本次活动的精确 source ID 执行测试 XACK/XDEL，并删除本次键、验证残留零。共享 Stream/group、每日 ID 序列与数据卷保留；失败轮强制清理不算成功 ACK 功能证据。
- 并发支付属于幂等与状态竞争正确性检查，不是持续吞吐量或容量指标。Linux race、远端 CI 与持续负载执行状态由整票报告说明。
