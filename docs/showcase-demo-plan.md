# 业务互动演示

2026-11-09。用户希望让HR和面试官实际操作，并要求围绕业务展开。延续现有浅紫静态站，在 `showcase/demo/` 实现独立演示；这是展示层的示例数据与状态模拟，不连接真实Go服务、模型、支付或云资源。

## 体验与规则

主流程为：发现门店与优惠 → 抢券受理/成单 → 模拟支付 → 切换店员核销 → 分享探店。引导说明当前业务目的并指向下一操作；也可自由切换顾客、商家和社区。页面始终显示静态演示标识，支持一键重置。

商家店员只在授权门店核销，退款需要店主角色；已核销不可退款，取消后可重买、退款后不可重买同一活动。库存、订单、核销凭证和操作记录在示例状态内联动。社区演示发布、关键词查询、点赞/取消，不增加收藏或“购买后才能发布”的业务限制。示例文本按纯文本显示，不加载外部资源。

所有交易为合成示例，数据仅保存在当前标签页的sessionStorage，禁用存储时降级为内存；不请求账号、手机号、密码或支付信息，不伪装真实认证或服务端权限。短暂处理中效果只说明受理和成单的差别，不作为后端时延或压测证据。
